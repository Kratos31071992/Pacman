# Pacman — Terminal Edition

Консольная 2D-игра Pacman на **C++20** без внешних библиотек. Проект превращён из стартового шаблона CLion в полноценную игру с лабиринтом, четырьмя призраками, энерджайзерами, жизнями, уровнями и сохранением рекорда.

Игровой движок отделён от терминального ввода и отрисовки, поэтому основную логику можно запускать и проверять без интерактивного терминала.

## Игровой процесс

- 31-строчный лабиринт с обычными точками и четырьмя энерджайзерами;
- плавная очередь поворотов: выбранное направление применяется на ближайшем доступном повороте;
- четыре призрака с разными стратегиями преследования и фазой разбегания по углам;
- после энерджайзера призраки становятся уязвимыми и двигаются медленнее;
- съеденный призрак возвращается в свою стартовую зону и возобновляет погоню;
- три жизни, дополнительная жизнь за каждые 10 000 очков, максимум пять;
- после сбора всех точек лабиринт обновляется, а следующий уровень становится сложнее;
- пауза, поражение, повторный запуск и сохранение рекорда между сеансами.

### Очки

| Действие | Очки |
|---|---:|
| Обычная точка | 10 |
| Энерджайзер | 50 |
| Призраки за один энерджайзер | 200, 400, 800, 1600 |

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` или стрелки | Движение |
| `Enter` или пробел | Начать игру / начать заново после поражения |
| `P` | Пауза / продолжить |
| `Q` | Выйти и сохранить рекорд |

Игру нужно запускать в интерактивном терминале с поддержкой ANSI-цветов.

## Требования

- CMake 3.16 или новее;
- компилятор с поддержкой C++20: GCC, Clang или MSVC;
- дополнительные пакеты и игровые движки не нужны.

## Сборка и запуск на macOS / Linux

```bash
git clone https://github.com/Kratos31071992/Pacman.git
cd Pacman
cmake -S . -B build
cmake --build build
./build/Pacman
```

Если CMake создал несколько конфигураций, исполняемый файл может находиться в подкаталоге `build/Debug`.

## Windows

```powershell
cmake -S . -B build
cmake --build build --config Debug
.\build\Debug\Pacman.exe
```

Ввод и включение ANSI-цветов для Windows реализованы отдельно, но фактическая проверка выполнялась в Linux-терминале.

## Тестирование

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

Для мультиконфигурационного генератора Windows добавьте `-C Debug` к команде `ctest`.

Девять групп тестов проверяют:

- стартовый экран и запуск;
- движение, стены и начисление очков;
- остановку мира на паузе;
- энерджайзер и поедание призрака;
- потерю трёх жизней, поражение и рестарт;
- завершение и переход на следующий уровень;
- сохранение рекорда при перезапуске;
- связность стандартного лабиринта и доступность всех точек;
- отклонение некорректных карт и спавнов.

Дополнительно выполнен интерактивный smoke-тест через псевдотерминал: проверены Enter, WASD, стрелки, пауза, продолжение, выход с кодом `0` и запись рекорда.

## Сохранение рекорда

Рекорд записывается в файл `.pacman_highscore` в каталоге, из которого запущена игра. Файл добавлен в `.gitignore`. При повреждении или отсутствии файла игра начинается с нулевого рекорда, а не падает.

## Ограничения

Это самостоятельная консольная интерпретация Pacman, а не точная копия аркадного оригинала. В игре нет графики, звука и сетевого режима. Лабиринт и поведение призраков упрощены, но все описанные выше игровые состояния реализованы и проверены.
