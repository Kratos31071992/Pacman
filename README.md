# Pacman

Учебный репозиторий для настройки простого проекта на C++ в CLion.

> **Текущий статус:** это заготовка, а не готовая игра. Название отражает исходную учебную идею, но игровая логика Pacman в текущей версии не реализована.

Сейчас программа выводит приветствие и числа от 1 до 13. Репозиторий можно использовать как минимальный пример сборки одного C++-файла через CMake.

## Технологии

- C++20;
- CMake 4.0 или новее;
- компилятор с поддержкой C++20: GCC, Clang или MSVC.

## Сборка и запуск

```bash
git clone https://github.com/Kratos31071992/Pacman.git
cd Pacman
cmake -S . -B build
cmake --build build
./build/Pacman
```

В Windows исполняемый файл может находиться по пути `build\Debug\Pacman.exe` или `build\Pacman.exe`, в зависимости от генератора CMake.

Ожидаемое начало вывода:

```text
Hello and welcome to C++!
i = 1
i = 2
```
